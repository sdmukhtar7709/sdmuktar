## ⚙️ Installation

Clone the repository.

```bash
git clone https://github.com/sdmukhtar7709/sdmuktar.git
```

Move into the project.

```bash
cd sdmuktar
```

Install dependencies.

```bash
npm install
```

Start the development server.

```bash
npm run dev
```

Build for production.

```bash
npm run build
```

Preview the production build.

```bash
npm run preview
```
